# Basis associativity experiments

Run from the repository root with Python 3.10 or newer:

```bash
python3 scripts/associativity.py --output /tmp/cayley-associativity
```

Add `--plot` to produce `associativity.png`; this optional step requires
matplotlib in your Python environment. Computation uses Python integers and
the package's `twist`, without a GPU or dense vectors.

The default run preserves the earlier measurements and adds controlled
experiments to distinguish mechanisms. It now collects:

- All **299,593 ordered triples** across exhaustive levels 0 through 6.
- **23 sampled levels through 16384**, 50,000 independent triples per regime
  and level (4.6 million main triples).
- **155 parameter sweeps**, 10,000 triples each, at levels 32, 128, and 1024.
- **93 mechanistic controls**, 25,000 triples each, at the same anchor levels.
- **793,182 exact support orderings**, for sparse weights 1 through 5.

The sampled budget is **8,475,000 triples**, plus paired perturbations and
exact enumerations. Expect several minutes. Each configuration prints
progress and checkpoints its CSV output. Level n means dimension 2**n;
index 0 represents the identity. Indices at level 16384 need only 16384 bits,
not a dense 2**16384-component vector.

The main levels are 3, 4, 5, 6, 8, 12, 16, 24, 32, 48, 64, 127, 128, 129,
256, 512, 1023, 1024, 1025, 2048, 4096, 8192, and 16384. Adjacent odd/even
levels test whether behavior previously sampled mostly at powers of two
persists between those levels.

To regenerate charts from a **completed** run without resampling:

```bash
python3 scripts/associativity.py --replot --output /tmp/cayley-associativity
```

For a quick run with the earlier scale:

```bash
python3 scripts/associativity.py --exhaustive-max 5 --levels 32 128 1024 \
  --samples 10000 --no-sweeps --no-studies --plot
```

For larger samples across the same levels:

```bash
python3 scripts/associativity.py --exhaustive-max 6 \
  --samples 200000 --sweep-samples 50000 --study-samples 100000 --seed 2026 \
  --plot --output /tmp/cayley-associativity-large
```

Enumeration costs 2**(3*n) triples. Levels above 6 require the explicit
`--allow-large-exhaustive` flag. Sampled runs allocate no 2**n arrays.

## Sampling distributions

- `uniform`: every bit of every index is independent with probability 1/2.
- `sparse`: each index has exactly `--weight` uniformly chosen set bits
  (default 3).
- `dense`: each index has exactly `--weight` uniformly chosen zero bits.
- `clustered`: choose a shared contiguous window of `--width` bits
  (default 8), with uniform bits inside it and zeros outside. The window
  start is uniform over its possible positions; width is capped at n.

Zeros and repeated indices are allowed by these distributions. The script
reports all triples, distinct nonzero triples, and F_2-independent triples
separately. For three indices, independence excludes zeros, repeated
indices, and a^b^c == 0. Sparse/dense weight must not exceed any sampled
level. Vary weight and width explicitly to compare different regimes;
fixed weight and fixed density are different experiments.

The additional sweeps vary:

- `--weights`: every integer from 1 through 12, then 16, 24, 32, for both
  sparse and dense indices. Consecutive weights help distinguish weight
  effects from weight-parity effects.
- `--densities`: 0, .01, .05, .1, .25, .5, .75, .9, .95, .99, 1. These use
  uniformly sampled fixed-weight indices with k = round(density*n), rather
  than independent Bernoulli bits. Output records the effective k/n.
- `--widths`: 1, 2, 3, 4, 6, 8, 12, 16, 32, 64, 128, 256, 512, 1024.

Weights/widths above each sweep level are omitted, and densities producing
identical k are deduplicated. `--sweep-levels` controls the anchor levels;
`--sweep-samples` controls each configuration's sample size. These sweeps
measure the overall rate, without neighbor probes. Use `--no-sweeps` to
omit them. Main `--regimes` selections apply to the main level sweep;
parameter sweeps are configured independently.

## Mechanistic controls

`--study-levels` and `--study-samples` configure the additional controls:

- **All eight Hamming-weight parity patterns.** Each argument is uniform
  within its specified even/odd class. A/b/c occupy bits 0/1/2, so the
  displayed binary pattern reads cba. This tests parity independently of
  fixing the complete weight.
- **Five adjacent weights near n/2.** Every index has exactly k ones, with
  k ranging from floor(n/2)-2 through floor(n/2)+2, clipped only for tiny n.
  This isolates nearby weight and parity effects at similar density.
- **Fixed weight versus independent Bernoulli bits.** At each requested
  `--study-densities` value (default .01, .05, .1, .25, .5, .75, .9, .95,
  .99), compare fixed k=round(p*n) to independently occupied positions.
  Independent bits are generated by parallel comparisons of independent
  16-bit random integers against round(p*65536). The exact effective
  probability and fixed-weight density are recorded; they can differ from
  the requested value, especially at small levels. Curves are not fitted.
- **Exact sparse support orderings.** `--order-max-weight` defaults to 5.
  For each k, enumerate every assignment of 3k occupied positions into
  three disjoint k-bit supports: (3k)!/(k!)**3 cases. Record pooled counts
  and counts by the owner of the lowest occupied bit, with reduced exact
  fractions. Unused gaps do not change twist, so these are exact
  conditional rates and fixed-k limits as n grows. Above k=5 requires
  `--allow-large-orderings` because the enumeration grows factorially.

Use `--no-studies` to omit these controls and exact support-order counts.
This is independent of `--no-sweeps`; both switches are needed to reproduce
only the earlier main level sweep.

Two further diagnostics use **every existing main triple**:

- `sparse_order.csv` separates pairwise-disjoint, nonzero supports from
  the rest, and records the lowest-bit owner. The disjoint population is
  also added to `summary.csv` as `disjoint_nonzero`.
- `rule_checks.csv` conditions perturbations on independence of the low-j
  prefixes. The tested prediction is: flipping bit j in a/c reverses R;
  flipping it in b or all three preserves R. The independent-prefix rule
  is checked by actual twist calls; outcomes are not imposed. For this
  table **failures means rule violations**, rather than R=-1. Counts for
  dependent prefixes are retained too. Under uniform sampling, the
  dependent-prefix probability bounds the unconditional violation rate.

The uniform analytical reference is
P(R=-1)=1/2-14*2**(-2*n)+24*2**(-3*n), with zero at n=0.
For independent triples at n>=3 it is 1/2+7/(2*(2**n-1)).
These formulas are derived counting references for this basis convention,
not statistical fits. Exact order counts and numerical agreement are not
claims that the corresponding mathematical results are new.

## Files

- `summary.csv`: failures, totals, rates, and pointwise 95% Wilson intervals
  for each stratum. Exhaustive intervals equal the exact rate.
- `overlap.csv`: marginal conditional rates and counts for pair/triple
  overlap, individual weights, XOR weight, and trailing-zero positions.
  Weight/overlap bucket k is floor(10*popcount/n); bucket 10 means full
  overlap. Trailing-zero buckets are exact positions, with -1 for zero.
  `ab_overlap_count` retains exact intersection sizes, and
  `pair_overlap_parity` records the parity of ab/ac/bc overlaps in bits 0/1/2.
- `signatures.csv`: frequencies of the three nonzero-associator flags in
  Type 1/2/3 order, separately for independent and degenerate triples.
  Frequencies use the total in that independence group as denominator.
- `neighbors.csv`: joint failure counts n00/n01/n10/n11, centered Pearson
  correlation, disagreement rate, and its Wilson interval. Perturbations
  flip one probe bit in each argument individually, flip that shared bit
  in all arguments, or increment a modulo 2**n. `bit_position` is the exact
  zero-based position, with -1 for increment. Each independent base chooses
  uniformly among probe positions: bits 0..7, powers of two and their 1.5x
  positions, and the highest bit. This resolves low-bit effects that coarse
  deciles hide. The overall mixture is uniform over probes, not all n bits.
- `structure.csv`: jointly conditions on the occupancy of the lowest
  occupied bit and the three pair-overlap parities, including counts,
  failures, and intervals. Occupancy stores a/b/c in bits 0/1/2.
- `sweeps.csv`: rates and intervals for weight, density, and width sweeps,
  with effective weight/width and actual density recorded explicitly.
- `studies.csv`: parity patterns, adjacent weights, and Bernoulli/fixed-weight
  comparisons. `parameter` is the pattern number, weight offset, or requested
  density according to `study`. Unused effective-weight/parity/density
  fields are -1; effective densities are recorded explicitly.
- `exact_orders.csv`: exact support-order counts and reduced fractions.
  `lowest_pattern=0` denotes all owners pooled; 1, 2, and 4 mean a, b, and c.
- `sparse_order.csv`: main-run rates split by disjointness and lowest-bit owner.
- `rule_checks.csv`: high-bit rule violation counts/intervals, split by prefix
  independence. `bit_position` is exact; there is no increment experiment here.
- `results.json`: all completed tables, used by `--replot`.
- `metadata.json`: arguments, seed, Python version, conventions, reference,
  per-configuration timings, schema version (3), script hash, probe positions,
  and budgets. Fixed seeds produce stable streams independently of
  configuration ordering. CSV files are deterministic; timings in metadata vary.
- `associativity.png` and `associativity.pdf`, with `--plot`: nine panels
  covering level dependence, fixed weights, density, cluster width,
  low-bit sensitivity, Pearson correlation, overlap parity, classification,
  and deviations from 1/2. Error bars show pointwise 95% Wilson intervals.
- `controls.png` and `controls.pdf`: six panels showing parity patterns,
  adjacent half-density weights, Bernoulli versus fixed-weight sampling,
  exact sparse-order limits, conditional lowest-bit-owner effects, and
  high-bit rule exceptions with a dependent-prefix probability bound.
- `structure.png`: four heatmaps of the joint binary features at the highest
  sampled level, with failure rate and count in each occupied cell. Blank
  cells have no observations. Binary category labels are displayed in the
  usual most-significant-bit-first order (c/b/a or bc/ac/ab).

If uniform sampling, parameter sweeps, or studies are omitted, their corresponding
panels have no data. Use the CSVs for all levels, arguments, and strata;
charts present selected comparisons.

Nearby triples are paired with independent base draws, rather than taken
from a random walk. Correlation is undefined (blank in CSV) when either
failure indicator has zero variance. Neighbor intervals describe
disagreement probability, not uncertainty in Pearson correlation.
Intervals are pointwise, without adjustment for multiple comparisons.

Overlap summaries are marginal, not joint structural classifications.
Coarse buckets can hide distinctions; evidence of a binary criterion
requires examining bit positions and searching for counterexamples.

## Classification and proof

The signature is the nonzero status of associators in these orderings:
`(a,c,b)`, `(a,b,c)`, `(b,a,c)`. On independent pure triads, labels
`100`, `010`, `001`, and `111` correspond to A, B, C, and X; `000` is
fully associative. Other signatures are retained as `unclassified`, and
degenerate triples are labeled separately.

These names follow [Wilmot, Structure of the Cayley-Dickson algebras,
v3, Section 3](https://arxiv.org/html/2505.11747v3#S3). The tests check the
permitted signature set at level 4 and independently validate twist and
bracketing signs using the recursive doubling rule. They do not establish
a general classification theorem or a limiting probability. To pursue a
proof, partition by the three highest bits and derive a closed recurrence
including any necessary zero/equality/XOR-dependence states.

Run the CPU-only checks with:

```bash
python3 -m pytest tests/test_associativity.py -q
```
